# Skill: Product User Journey Optimizer

This custom skill helps the Product Owner analyze, design, and optimize user experience flows, onboarding journeys, and UI copy, reducing drop-offs and friction.

## How to Use

To audit or optimize a user journey, trigger this skill by asking:

> "Optimize the user journey for [Feature/Action Name] and suggest UX/microcopy changes."

The skill will return a journey optimization report detailing friction points, solutions, and copy updates.
