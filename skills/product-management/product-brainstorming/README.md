# Skill: Product Brainstormer

This custom skill helps the Product Owner ideate, explore, and conceptualize raw product and feature ideas before formal prioritization and requirement specification. It uses framework models to map the user journey value proposition and user hook.

## How to Use

To begin brainstorming a new product or feature concept, trigger this skill by asking:

> "I want to brainstorm a new feature idea: [Feature Name]"

The skill will guide you through:
1. **Core Problem & Persona Alignment**: Finding the Jobs-to-be-Done.
2. **Behavioral Engagement Mapping**: Exploring triggers, actions, variable rewards, and user investments.
3. **Divergent Concept Exploration**: Suggesting multiple creative, low-friction, or AI-first options to solve the job.
4. **Validation Mapping**: Highlighting key assumptions and how to test them.
