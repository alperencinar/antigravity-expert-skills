# Antigravity Skill Activation (product-antigravity-skill-activate)

A specialized utility skill to configure, register, and activate custom skills within the Antigravity developer environment.

## When to Use

Use this skill when:
- A new skill is created but is not showing up or cannot be called in the interface.
- You need to register project-scoped skills in `.agents/skills.json`.
- You want to ensure files are placed in the correct global or workspace roots.

## Triggers

This skill triggers automatically on queries matching:
- `activate antigravity skill`
- `register antigravity skill`
- `configure skill in agents`
- `antigravity skill activate`
