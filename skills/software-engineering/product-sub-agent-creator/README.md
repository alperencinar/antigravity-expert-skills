# Skill: Product Sub-Agent Creator

This custom skill acts as a Mastermind Architect, decomposing complex feature requests or refactoring goals into independent sub-tasks, defining specialized sub-agents, and orchestrating their execution.

## How to Use

To begin decomposing and implementing a complex task using sub-agents, trigger this skill by asking:

> "Decompose and implement the feature [Feature/Refactor Name] using specialized sub-agents."

The skill will guide you through the planning, decomposition, instantiation, and execution monitoring phases.
