# Skill: Selecting Development Technology

This skill helps technical leaders and product owners systematically evaluate and choose the best technologies, databases, and frameworks for a feature or product based on requirements, cost boundaries, and maintenance constraints.

## How to Use

To begin technology stack evaluation and document decisions:

> "Run product-selecting-development-technology to evaluate database options for our new analytics dashboard."
> "Compare React Native and Flutter for our mobile app project."

The skill will perform comparative analysis using a standardized Evaluation Matrix and generate formal Architecture Decision Records (ADRs) for project archives.
