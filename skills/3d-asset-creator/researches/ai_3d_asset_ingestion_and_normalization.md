# AI 3D Model Ingestion & FBX Normalization in Unity URP

This technical reference provides an end-to-end architecture and production-grade implementation for ingesting, normalizing, and instantiating 3D assets generated by AI pipelines (such as Meshy AI, Tripo AI, CSM, or Rodin) within Unity's Universal Render Pipeline (URP).

---

## 1. Meshy AI & Tripo AI Raw Mesh Quirks & Artifacts

Generative AI 3D engines construct geometry and textures via NeRF, Gaussian Splatting, or Marching Cubes/Triplane diffusion algorithms. When converted to polygonal meshes and exported as FBX or GLB, the resulting assets exhibit systematic structural anomalies that break standard game engine workflows.

```
       RAW AI FBX EXPORT                             UNITY URP NORMALIZED ASSET
  +--------------------------+                     +-------------------------------+
  | - Off-center Floating    |                     | - Bottom-Center Pivot (0,0,0) |
  |   Pivot Point            |                     | - Scaled to Standard Units    |
  | - Arbitrary Units (100x) |  ===> PIPELINE ==>  | - 60° Smooth Normals          |
  | - Missing Tangents       |                     | - MikkTSpace Tangents         |
  | - Flipped Face Winding   |                     | - Opaque PNG BaseColor        |
  | - Embedded Alpha Channel |                     | - Clean Root/Child Structure  |
  +--------------------------+                     +-------------------------------+
```

### 1.1 Arbitrary Bounding Scale & Axis Discrepancies
* **Blender vs Unity FBX Unit Mismatch:** DCC tools and AI pipelines often export FBX files using centimeter units ($1\text{ unit} = 0.01\text{m}$) or arbitrary normalized bounding boxes ($[-1, 1]$ cube space). Importing without explicit unit baking produces an unwanted `100.0` or `0.01` transform scale on root GameObjects in Unity.
* **Non-Uniform Axis Scaling:** AI meshes frequently present non-uniform scale factors across local axes $(S_x \neq S_y \neq S_z)$, causing distortion when parented or rotated.

### 1.2 Missing or Zero-Vector Tangents
* **Tangent Space Omission:** Most AI export pipelines omit tangent vectors entirely or output zero vectors `(0,0,0,0)`.
* **Shading Breakage in URP:** URP's `Universal Render Pipeline/Lit` shader requires valid 4D tangent vectors (where the 4th component defines bitangent sign/handedness). Missing tangents cause dark surface artifacts, invalid normal map calculations, and broken specular highlights.

### 1.3 Flipped Normals & Inverted Face Winding
* **Marching Cubes Artifacts:** Iso-surface extraction algorithms occasionally produce flipped triangle indices ($v_0 \to v_2 \to v_1$), causing backface culling to invert (making outer surfaces invisible while inner surfaces render).
* **Hard Edge Creases:** Default normal generation in raw AI models often creates hard lighting seams along UV chart boundaries or produces 0-degree faceted shading.

### 1.4 Floating & Off-Center Pivots
* **Center of Mass Placement:** Raw AI assets place the mesh origin $(0,0,0)$ at the center of the bounding volume or at an arbitrary offset corresponding to the generation camera grid.
* **Physics & Grounding Failures:** Placing an off-center pivot asset into a Unity scene causes the model to sink into terrain or float above ground surfaces when set to position $Y=0$.

## 2. Automated `AssetPostprocessor` Normalization Pipeline

Unity's `AssetPostprocessor` class provides editor hooks to intercept asset import events. By inheriting from `AssetPostprocessor`, we enforce scale baking, calculate 60-degree smooth normals, and generate MikkTSpace tangents automatically upon importing raw AI assets.

### 2.1 C# Importer Implementation (`AIModelPostprocessor.cs`)

Save the following file in an `Editor` directory (e.g., `Assets/Scripts/Editor/AIModelPostprocessor.cs`):

```csharp
using UnityEngine;
using UnityEditor;
using System.IO;

namespace UnityExpert.AIAssetPipeline
{
    /// <summary>
    /// Automated ModelImporter post-processor designed for AI-generated 3D assets
    /// (Meshy AI, Tripo AI, CSM, Rodin). Normalizes scale, normal vector smooth angles,
    /// and MikkTSpace tangent spaces.
    /// </summary>
    public class AIModelPostprocessor : AssetPostprocessor
    {
        private const string AI_ASSET_FOLDER_KEYWORD = "AI_Imports";
        private const float SMOOTH_NORMAL_ANGLE = 60.0f;

        /// <summary>
        /// Hook executed before model geometry is imported.
        /// Configures ModelImporter settings programmatically.
        /// </summary>
        private void OnPreprocessModel()
        {
            ModelImporter modelImporter = assetImporter as ModelImporter;
            if (modelImporter == null) return;

            // Target only models placed in AI pipeline ingestion directories
            if (!assetPath.Contains(AI_ASSET_FOLDER_KEYWORD) && !assetPath.ToLower().Contains("meshy"))
            {
                return;
            }

            Debug.Log($"[AIModelPostprocessor] Normalizing Import Settings for: {assetPath}");

            // 1. Scale & Unit Normalization
            modelImporter.globalScale = 1.0f;
            modelImporter.useFileUnits = true;
            modelImporter.bakeAxisConversion = true;
            modelImporter.importBlendShapes = false;
            modelImporter.isReadable = true; // Required for CPU vertex access during pivot baking

            // 2. Normal Recalculation with 60-Degree Smooth Angle
            modelImporter.importNormals = ModelImporterNormals.Calculate;
            modelImporter.normalCalculationMode = ModelImporterNormalCalculationMode.AreaAndAngleWeighted;
            modelImporter.normalSmoothingAngle = SMOOTH_NORMAL_ANGLE;

            // 3. MikkTSpace Tangent Generation
            modelImporter.importTangents = ModelImporterTangents.CalculateMikkTSpace;

            // 4. Material & Geometry Optimization
            modelImporter.materialImportMode = ModelImporterMaterialImportMode.ImportViaMaterialDescription;
            modelImporter.materialLocation = ModelImporterMaterialLocation.InPrefab;
            modelImporter.weldVertices = true;
            modelImporter.optimizeMeshPolygons = true;
            modelImporter.optimizeMeshVertices = true;
        }

        /// <summary>
        /// Hook executed after model mesh assets have been constructed.
        /// Enforces vertex-level pivot recalibration (ground-anchoring).
        /// </summary>
        private void OnPostprocessModel(GameObject root)
        {
            if (!assetPath.Contains(AI_ASSET_FOLDER_KEYWORD) && !assetPath.ToLower().Contains("meshy"))
            {
                return;
            }

            // Recalibrate pivot vertices so ground position is (0, 0, 0)
            BakeGroundPivot(root);
        }

        /// <summary>
        /// Shifts all child mesh vertices so the lowest point of the combined bounding box
        /// rests at Y = 0, and the X/Z center aligns with 0,0.
        /// </summary>
        private static void BakeGroundPivot(GameObject rootTarget)
        {
            MeshFilter[] meshFilters = rootTarget.GetComponentsInChildren<MeshFilter>();
            if (meshFilters.Length == 0) return;

            // Calculate combined bounds across all child mesh filters
            Bounds combinedBounds = new Bounds();
            bool boundsInitialized = false;

            foreach (var mf in meshFilters)
            {
                if (mf.sharedMesh == null) continue;
                
                Bounds b = mf.sharedMesh.bounds;
                // Transform local bounds to root space
                Vector3 worldMin = mf.transform.TransformPoint(b.min);
                Vector3 worldMax = mf.transform.TransformPoint(b.max);

                Bounds rootSpaceBounds = new Bounds((worldMin + worldMax) * 0.5f, worldMax - worldMin);

                if (!boundsInitialized)
                {
                    combinedBounds = rootSpaceBounds;
                    boundsInitialized = true;
                }
                else
                {
                    combinedBounds.Encapsulate(rootSpaceBounds);
                }
            }

            if (!boundsInitialized) return;

            // Offset vector: Moves bottom center of bounds to (0,0,0) in local space
            Vector3 offset = new Vector3(-combinedBounds.center.x, -combinedBounds.min.y, -combinedBounds.center.z);

            // Apply vertex position shift to make the offset permanent in mesh geometry
            foreach (var mf in meshFilters)
            {
                Mesh mesh = mf.sharedMesh;
                if (mesh == null) continue;

                // Duplicate mesh instance to modify vertex buffers safely
                Vector3[] vertices = mesh.vertices;
                Vector3 localOffset = mf.transform.InverseTransformDirection(offset);

                for (int i = 0; i < vertices.Length; i++)
                {
                    vertices[i] += localOffset;
                }

                mesh.vertices = vertices;
                mesh.RecalculateBounds();
            }

            Debug.Log($"[AIModelPostprocessor] Baked bottom-center ground pivot for '{rootTarget.name}' (Offset: {offset})");
        }
    }
}
```

## 3. Programmatic Pivot Ground-Anchoring & Alignment

### 3.1 Mathematical Principles of Vertex Recalibration
Ground anchoring recalibrates the vertex array $V = \{v_1, v_2, \dots, v_n\}$ of a 3D mesh relative to its bounding box $B$:

$$\text{Bounds Center: } C = \left( \frac{B_{\text{max},x} + B_{\text{min},x}}{2}, \frac{B_{\text{max},y} + B_{\text{min},y}}{2}, \frac{B_{\text{max},z} + B_{\text{min},z}}{2} \right)$$

$$\text{Offset Vector: } \vec{O} = \left( -C_x, -B_{\text{min},y}, -C_z \right)$$

$$\text{New Vertex Position: } v_i' = v_i + \vec{O}$$

This translation guarantees:
1. $Y_{\text{min}} = 0.0$ (Bottom-center aligned to origin ground plane).
2. $X_{\text{center}} = 0.0, Z_{\text{center}} = 0.0$ (Centered laterally).

```
   BEFORE GROUND ANCHORING                    AFTER GROUND ANCHORING
          +------+                                   +------+
          | Mesh |                                   | Mesh |
          +------+                                   +------+
-------------O----------------          ----------------O---------------- (Y = 0)
        (Pivot at origin)                   (Pivot anchored at bottom center)
```

## 4. Entity Architecture: Root vs Child Node Separation

In production Unity game design, physical entities (characters, props, vehicles) **must never** attach `Rigidbody` or `Collider` components to the same GameObject node that contains non-uniform scales, raw AI MeshFilters, or procedural animation offsets.

```
[Entity Root GameObject] -------------------- Scale: (1, 1, 1) UNIFORM
 ├── Rigidbody (IsKinematic / Dynamic)
 ├── BoxCollider / CapsuleCollider (Fits ground-anchored bounds)
 ├── Entity Logic Scripts (CharacterController, AI Agent)
 └── [Visual Container Node] ----------------- Transform Offset / Local Rotation
      └── [Mesh Sub-Node] ------------------- MeshRenderer + MeshFilter (URP Lit Material)
```

### 4.1 Why Separation is Mandatory
1. **PhysX Scale Invariance:** PhysX scale updates are computationally expensive and trigger continuous recalculation of inertia tensors. Non-uniform scales on a `Rigidbody` root result in erratic physics collisions.
2. **Animation Isolation:** Procedural bobbing, squashing, or mesh-shake effects can be applied to the `Visual Container` without affecting the `Rigidbody` or `Collider` bounding box.
3. **Hot-Swappable AI Meshes:** Replacing an AI mesh asset requires swapping only the `Visual Container` child node while retaining all physics, scripts, and network IDs on the Root entity.

### 4.2 Automated Entity Factory Implementation (`AIEntityFactory.cs`)

Save the following runtime utility script to build production-ready entity hierarchies from raw AI models:

```csharp
using UnityEngine;

namespace UnityExpert.AIAssetPipeline
{
    /// <summary>
    /// Factory for instantiating normalized AI assets into safe Unity Root/Child entity structures.
    /// </summary>
    public static class AIEntityFactory
    {
        public static GameObject CreatePhysicsEntity(GameObject rawAiPrefab, Vector3 spawnPosition, Quaternion spawnRotation)
        {
            // 1. Create Root Entity GameObject (Pristine Transform)
            GameObject rootEntity = new GameObject($"{rawAiPrefab.name}_Entity");
            rootEntity.transform.position = spawnPosition;
            rootEntity.transform.rotation = spawnRotation;
            rootEntity.transform.localScale = Vector3.one;

            // 2. Instantiate Visual Child Container
            GameObject visualContainer = new GameObject("Visual_Container");
            visualContainer.transform.SetParent(rootEntity.transform, false);
            visualContainer.transform.localPosition = Vector3.zero;
            visualContainer.transform.localRotation = Quaternion.identity;
            visualContainer.transform.localScale = Vector3.one;

            // 3. Instantiate AI Mesh Prefab under Visual Container
            GameObject meshInstance = Object.Instantiate(rawAiPrefab, visualContainer.transform);
            meshInstance.name = "AI_Mesh_Node";

            // 4. Compute Bounding Box for Physics Component Placement
            Renderer[] renderers = rootEntity.GetComponentsInChildren<Renderer>();
            if (renderers.Length > 0)
            {
                Bounds combinedBounds = renderers[0].bounds;
                for (int i = 1; i < renderers.Length; i++)
                {
                    combinedBounds.Encapsulate(renderers[i].bounds);
                }

                // 5. Add Rigidbody with Standard Dynamics
                Rigidbody rb = rootEntity.AddComponent<Rigidbody>();
                rb.mass = 1.0f;
                rb.interpolation = RigidbodyInterpolation.Interpolate;
                rb.collisionDetectionMode = CollisionDetectionMode.ContinuousSpeculative;

                // 6. Add BoxCollider Centered Precisely Over Ground-Anchored Mesh
                BoxCollider boxCollider = rootEntity.AddComponent<BoxCollider>();
                Vector3 localCenter = rootEntity.transform.InverseTransformPoint(combinedBounds.center);
                Vector3 localSize = combinedBounds.size;

                boxCollider.center = localCenter;
                boxCollider.size = localSize;
            }

            return rootEntity;
        }
    }
}
```

## 5. BaseColor PNG Alpha Channel Texture Importer Pipeline

### 5.1 The Embedded Alpha Channel Problem
AI texture generators (e.g., Meshy, Tripo, Stability AI) export 32-bit PNG `BaseColor` (Albedo) maps containing an embedded alpha channel. In many cases, this alpha channel is populated with solid black (`0`) or erratic transparency values despite the texture representing an fully opaque physical material.

When imported into Unity:
1. `TextureImporter` defaults to `alphaSource = InputAlpha`.
2. URP Shader Graph and standard `Universal Render Pipeline/Lit` materials inspect the texture alpha channel.
3. If the material surface mode is toggled or referenced by URP transparent passes, the mesh renders as **completely invisible** or **partially see-through**.

```
[ AI Texture Generator ] === (32-bit PNG with Black Alpha) ===> [ Unity URP Shader ]
                                                                       │
                                                       (Renders Mesh Invisible!)
                                                                       │
                                                                       ▼
                                                    FIX: TextureImporter Override
                                                    alphaSource = None
                                                    alphaIsTransparency = false
```

### 5.2 C# Texture Importer Implementation (`AITexturePostprocessor.cs`)

Save the following script in an `Editor` folder (e.g., `Assets/Scripts/Editor/AITexturePostprocessor.cs`):

```csharp
using UnityEngine;
using UnityEditor;

namespace UnityExpert.AIAssetPipeline
{
    /// <summary>
    /// Intercepts AI texture imports to strip unwanted PNG alpha channels from BaseColor textures,
    /// ensuring correct rendering under URP Lit materials.
    /// </summary>
    public class AITexturePostprocessor : AssetPostprocessor
    {
        private const string AI_ASSET_FOLDER_KEYWORD = "AI_Imports";

        private void OnPreprocessTexture()
        {
            TextureImporter textureImporter = assetImporter as TextureImporter;
            if (textureImporter == null) return;

            // Target textures located in AI Asset directories or containing common AI suffixes
            string pathLower = assetPath.ToLower();
            bool isAiTexture = assetPath.Contains(AI_ASSET_FOLDER_KEYWORD) ||
                               pathLower.Contains("meshy") ||
                               pathLower.Contains("basecolor") ||
                               pathLower.Contains("albedo");

            if (!isAiTexture) return;

            Debug.Log($"[AITexturePostprocessor] Strip Alpha / Fix URP Settings for: {assetPath}");

            // 1. Force Disable Alpha Processing for BaseColor / Albedo Textures
            if (pathLower.Contains("basecolor") || pathLower.Contains("albedo") || pathLower.Contains("diffuse"))
            {
                textureImporter.alphaSource = TextureImporterAlphaSource.None;
                textureImporter.alphaIsTransparency = false;
                textureImporter.sRGBTexture = true; // Color map requires sRGB space
            }
            // 2. Normal Map Specific Settings
            else if (pathLower.Contains("normal"))
            {
                textureImporter.textureType = TextureImporterType.NormalMap;
                textureImporter.convertToNormalmap = false;
            }
            // 3. Metallic / Roughness / Occlusion Mask Maps
            else if (pathLower.Contains("metallic") || pathLower.Contains("roughness") || pathLower.Contains("orm"))
            {
                textureImporter.textureType = TextureImporterType.Default;
                textureImporter.sRGBTexture = false; // Linear data for mask maps
                textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
            }

            // High Quality Compression Settings
            textureImporter.mipmapEnabled = true;
            textureImporter.mipmapFilter = TextureImporterMipFilter.KaiserFilter;
            textureImporter.textureCompression = TextureImporterCompression.CompressedHQ;
        }
    }
}
```

## 6. Verification & Quality Checklist

Before deploying AI-generated assets into production scenes, execute this verification protocol:

| Check | Expected Result | Pass Criteria |
| :--- | :--- | :--- |
| **Transform Scale** | Root scale is `(1.0, 1.0, 1.0)` | No parent `100.0` or `0.01` scale offsets in Inspector. |
| **Pivot Placement** | Ground-anchored bottom center | Asset sits flush on $Y=0.0$ plane when instantiated. |
| **Spawner Y-Offset Retention** | `childModel.localPosition.y` preserved | Spawner/pooling scripts lock root to $Y=0$ without zeroing child model Y-offset. |
| **Safe Tag & Layer Assignment** | Checked `NameToLayer` & `try-catch` tag | Editor setup scripts do not crash on missing layers or undefined tags. |
| **Normals & Tangents** | MikkTSpace tangents active | URP Lit shader normal maps render without black seams. |
| **Smooth Angle** | 60.0 Degrees applied | Faceted AI polygon boundaries appear smoothly shaded. |
| **Texture Alpha** | `Alpha Source = None` on BaseColor | Model renders fully opaque in URP scene view. |
| **Physics Hierarchy** | Root Node owns `Rigidbody` + `Collider` | Mesh node scale is uniform; PhysX collision is stable. |
