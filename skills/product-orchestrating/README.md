# Skill: Product Orchestrator

This custom skill coordinates all product-facing skills in the workspace, guiding the Product Owner through a structured product development lifecycle.

## How to Use

To begin planning or managing a feature lifecycle, trigger this skill by asking:

> "Orchestrate the development lifecycle for the new feature [Feature Name]."

The skill will evaluate the current phase, guide you through prioritization, market analysis, specs definition, UX optimization, and documentation, delegating to the appropriate `product-*` skills at each step.

### Help & Tool Lookup

You can also use this skill as a directory to find the right tool for a task or to get an overview of all product skills. Trigger it by asking:

> "What product skills do we have?"
> "Which skill should I use for competitor analysis?"
