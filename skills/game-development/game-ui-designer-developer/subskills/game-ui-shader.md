# /game-ui-shader - Glassmorphism, Neon Glow & Technical Art Shaders

## UI Shader Motoru

1. **Glassmorphism Blur Shader**: URP Downsampled Kawase Blur + Chromatic Aberration & Rim Lighting (`UI_Glassmorphism_URP.shader`).
2. **Glowing Outline Shader**: 8-tap alpha dilate + sinüs pulse falloff (`UI_GlowingOutline_URP.shader`).
3. **Procedural Rounded Corners**: Bağımsız 4 köşe SDF radius hesabı + antialiased stroke (`UI_ProceduralRoundedCorners_URP.shader`).
4. **Holographic Shimmer**: Nadir kartlar/rozetler için anizotropik specular süpürme yansıması.
