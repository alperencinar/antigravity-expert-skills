# Skill: Product Prioritization Navigator

This custom skill helps the Product Owner prioritize features and manage the product backlog using RICE and MoSCoW frameworks, with specific checks for product and API cost economics.

## How to Use

To evaluate a feature candidate, trigger this skill by asking:

> "Evaluate the priority of the proposed feature [Feature Name] and calculate its RICE/MoSCoW score."

The skill will return a comprehensive backlog evaluation report including a recommendation on whether to build, defer, or discard.
