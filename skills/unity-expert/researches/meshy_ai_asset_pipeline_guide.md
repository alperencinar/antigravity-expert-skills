# Meshy AI 3D Asset Import & Normalization Pipeline in Unity URP

## Executive Summary

Generative AI 3D platforms such as **Meshy AI** produce high-fidelity textured 3D meshes (FBX/GLTF/GLB) rapidly. However, raw model exports from AI generation pipelines present significant technical integration challenges in production game engines like Unity (Universal Render Pipeline - URP). 

Key issues include:
- Inconsistent coordinate systems and scale factors (e.g. Blender vs Maya vs Unity scale standards).
- Non-standard pivot placement (center of bounding box vs bottom-center grounded pivot).
- Artifacts in lighting due to missing or improperly computed vertex normals and tangents.
- Material/Shader breakage caused by unintended PNG alpha channels in BaseColor textures (rendering materials as transparent or fully invisible under URP Lit shaders).
- Tight coupling of mesh visuals and physics colliders, leading to physics instability and rigid body jitter.

This technical guide establishes an **automated, production-grade Unity C# Editor pipeline** (`AssetPostprocessor` & Editor Automation) designed to import, normalize, isolate, and material-assign Meshy AI assets seamlessly into Unity URP projects.

## 1. Automated FBX ModelImporter Scripting

When importing FBX files generated by Meshy AI, Unity's default importer settings often produce models with arbitrary scales (e.g., 0.01 scale factor from Maya conversions), incorrect lighting response, and improper surface tangents.

### Key Importer Configurations

1. **Scale Baking (`globalScale`, `bakeAxisConversion`)**:
   - Unity uses 1 unit = 1 meter. Meshy AI exports often use 1 unit = 1 centimeter or arbitrary units.
   - Setting `globalScale = 1.0f` and enforcing `useFileScale = false` prevents nested scaling issues.
   - `bakeAxisConversion = true` converts Blender/OpenGL coordinate systems (+Z up or -Z forward) directly into Unity's coordinate system (+Y up, +Z forward).

2. **Normals & Tangent Calculation**:
   - AI-generated meshes frequently contain split normals, flat shading, or corrupted normal attributes.
   - `importNormals = ModelImporterNormals.Calculate` forces Unity to calculate smooth normals across adjacent polygons.
   - `normalSmoothingAngle = 60.0f` provides optimal curvature smoothing for stylized and semi-realistic AI assets without blurring sharp hard edges.
   - `importTangents = ModelImporterTangents.CalculateMikk` applies the industry-standard **MikkTSpace** algorithm, ensuring normal maps render without seam artifacts or inverted shading under URP lighting.

### C# Importer Script (`MeshyModelPostprocessor.cs`)

```csharp
#if UNITY_EDITOR
using UnityEditor;
using UnityEngine;

namespace Pipeline.MeshyAI
{
    public class MeshyModelPostprocessor : AssetPostprocessor
    {
        // Define directory prefix for targeted postprocessing
        private const string MeshyAssetFolder = "Assets/Art/MeshyAI/";

        private bool IsMeshyAsset => assetPath.StartsWith(MeshyAssetFolder, System.StringComparison.OrdinalIgnoreCase);

        private void OnPreprocessModel()
        {
            if (!IsMeshyAsset) return;

            ModelImporter importer = (ModelImporter)assetImporter;

            // 1. Scale and Coordinate Axis Normalization
            importer.globalScale = 1.0f;
            importer.useFileScale = false;
            importer.bakeAxisConversion = true; // Bakes axis conversion directly into geometry
            importer.importUnits = ModelImporterLengthUnit.Meters;

            // 2. Geometry Optimization
            importer.isReadable = true; // Required for runtime/editor pivot calculation & collision mesh generation
            importer.optimizeMeshPolygons = true;
            importer.optimizeMeshVertices = true;
            importer.meshCompression = ModelImporterMeshCompression.Off; // Set to Medium/High for production mobile builds

            // 3. Normals & Tangents Configuration
            importer.importNormals = ModelImporterNormals.Calculate;
            importer.normalSmoothingAngle = 60.0f; // 60 degrees threshold for smooth shading
            importer.normalCalculationMode = ModelImporterNormalCalculationMode.AreaAndAngleWeighted;
            importer.importTangents = ModelImporterTangents.CalculateMikk; // MikkTSpace standard

            // 4. Material & Animation Handling
            importer.materialImportMode = ModelImporterMaterialImportMode.ImportViaMaterialDescription;
            importer.importAnimation = true; // Allow rigs if model is animated by Meshy AI
        }
    }
}
#endif
```

## 2. Pivot Normalization (Bottom-Center `0,0,0`, `+Z` Forward)

Meshy AI exports assets centered around the geometric center of mass or world origin. For game entities (characters, props, obstacles, vehicles), the pivot point must strictly reside at the **bottom-center `(0,0,0)`** of the object's local bounding box, with the forward vector facing **`+Z` (Vector3.forward)**.

### Pivot Adjustment Strategy

Modifying FBX mesh vertices directly on disk alters original source files and introduces mesh re-import overhead. Instead, the pipeline uses a **Non-Destructive Scene/Prefab Offset Structure**:

1. Calculate combined local bounds of all `MeshFilter` components under the model root.
2. Determine bottom-center position: `bottomCenter = new Vector3(bounds.center.x, bounds.min.y, bounds.center.z)`.
3. Create a **Visual Parent Container** shifted by `-bottomCenter` to offset the raw mesh so that its lowest point aligns exactly with local `Y = 0`.
4. Ensure rotation offset aligns the front face toward Unity's native `+Z` forward axis.

## 3. Visual vs Collider Hierarchy Isolation

Directly attaching `Rigidbody`, physics `Collider` components, and gameplay scripts to the same GameObject containing the `MeshRenderer` causes critical architectural issues:

- **Physics Skewing**: Scaling the visual mesh directly non-uniformly skews collider detection and raycasting.
- **Rotation Lock-in**: Offsetting mesh rotation to fix facing direction skews physics forces (e.g. `AddForce(transform.forward)` pushes sideways).
- **Animation Artifacts**: Root motion or animation transforms mutate root physics parameters.

### Standard Normalized Hierarchy Structure

```
[Entity Root]  <-- Position (World Ground), Rotation (+Z Facing)
 │  ├── Rigidbody (IsKinematic / Dynamic)
 │  ├── CapsuleCollider / BoxCollider (Encloses full entity bounds)
 │  └── Gameplay/Network Scripts
 │
 └── Visuals_Parent  <-- Local Offset Vector (-bottomCenter)
      └── Meshy_Model_Node  <-- Raw FBX Import Node (Scale: 1,1,1)
           ├── MeshFilter
           ├── MeshRenderer (URP Lit Material)
           └── Animator (if applicable)
```

## 4. BaseColor PNG Texture Alpha Handling (`alphaSource = None`)

### The Issue with Meshy AI PNG Textures

Meshy AI exports BaseColor/Albedo maps in standard PNG format. Many PNG exporters encode a default 8-bit alpha channel (values all 0 or all 255) even when transparency is not intended. 

When imported into Unity:
- By default, Unity sets `alphaSource = InputAlpha` and enables `alphaIsTransparency`.
- The URP Lit shader reads the alpha channel as surface opacity.
- **Result**: Models render completely invisible, pitch black, or with semi-transparent hole artifacts across opaque surfaces.

### Automated Texture Import Fix

Using `AssetPostprocessor.OnPreprocessTexture`, the pipeline checks for BaseColor/Albedo texture naming patterns and forces:
- `textureImporter.alphaSource = TextureImporterAlphaSource.None` (completely strip alpha channel during import).
- `textureImporter.sRGBTexture = true` (ensure color map uses sRGB gamma for correct PBR color rendering).
- For Normal maps: `textureType = TextureImporterType.NormalMap`.
- For Metallic/Roughness maps: `sRGBTexture = false` (linear data channel).

### C# Texture Importer Script (`MeshyTexturePostprocessor.cs`)

```csharp
#if UNITY_EDITOR
using UnityEditor;
using UnityEngine;

namespace Pipeline.MeshyAI
{
    public class MeshyTexturePostprocessor : AssetPostprocessor
    {
        private const string MeshyAssetFolder = "Assets/Art/MeshyAI/";

        private bool IsMeshyAsset => assetPath.StartsWith(MeshyAssetFolder, System.StringComparison.OrdinalIgnoreCase);

        private void OnPreprocessTexture()
        {
            if (!IsMeshyAsset) return;

            TextureImporter textureImporter = (TextureImporter)assetImporter;
            string fileName = System.IO.Path.GetFileNameWithoutExtension(assetPath).ToLower();

            // 1. BaseColor / Albedo Handling
            if (fileName.Contains("basecolor") || fileName.Contains("albedo") || fileName.Contains("diffuse") || fileName.Contains("color"))
            {
                textureImporter.textureType = TextureImporterType.Default;
                textureImporter.sRGBTexture = true; // Must be sRGB for BaseColor
                
                // CRITICAL FIX: Force strip unintended alpha channel from Meshy AI PNG exports
                textureImporter.alphaSource = TextureImporterAlphaSource.None;
                textureImporter.alphaIsTransparency = false;
            }
            // 2. Normal Map Handling
            else if (fileName.Contains("normal") || fileName.Contains("norm") || fileName.EndsWith("_n"))
            {
                textureImporter.textureType = TextureImporterType.NormalMap;
                textureImporter.convertToNormalMap = false;
                textureImporter.sRGBTexture = false; // Linear data
            }
            // 3. Metallic / Roughness / Occlusion Data Maps
            else if (fileName.Contains("metallic") || fileName.Contains("roughness") || fileName.Contains("orm") || fileName.Contains("arm"))
            {
                textureImporter.textureType = TextureImporterType.Default;
                textureImporter.sRGBTexture = false; // Must be Linear (sRGB off)
                textureImporter.alphaSource = TextureImporterAlphaSource.FromInputAlpha;
            }
        }
    }
}
#endif
```

## 5. Complete Pipeline & Prefab Builder Automation

The following C# Editor Script automates the entire process: taking raw imported FBX models from Meshy AI, computing bounds, building isolated physics/visual hierarchies, normalizing pivots to bottom-center `(0,0,0)`, creating URP Lit materials, and outputting production-ready prefabs.

### Automated Prefab Generator Script (`MeshyPipelineBuilder.cs`)

```csharp
#if UNITY_EDITOR
using System.IO;
using UnityEditor;
using UnityEngine;

namespace Pipeline.MeshyAI
{
    public static class MeshyPipelineBuilder
    {
        [MenuItem("Tools/Meshy AI/Normalize & Build Selected Model Prefab")]
        public static void BuildNormalizedPrefabFromSelection()
        {
            GameObject selectedObject = Selection.activeGameObject;
            if (selectedObject == null)
            {
                EditorUtility.DisplayDialog("Error", "Please select a Meshy AI FBX GameObject in the Hierarchy or Project view.", "OK");
                return;
            }

            string assetPath = AssetDatabase.GetAssetPath(selectedObject);
            if (string.IsNullOrEmpty(assetPath))
            {
                EditorUtility.DisplayDialog("Error", "Selected object must be an asset file (FBX).", "OK");
                return;
            }

            // Step 1: Instantiate instance for normalization
            GameObject rawInstance = Object.Instantiate(selectedObject);
            rawInstance.name = selectedObject.name + "_Raw";

            // Step 2: Compute Mesh Bounds across all child meshes
            MeshRenderer[] renderers = rawInstance.GetComponentsInChildren<MeshRenderer>();
            if (renderers.Length == 0)
            {
                Debug.LogError("[MeshyPipeline] No MeshRenderers found on selected asset.");
                Object.DestroyImmediate(rawInstance);
                return;
            }

            Bounds combinedBounds = renderers[0].bounds;
            foreach (MeshRenderer renderer in renderers)
            {
                combinedBounds.Encapsulate(renderer.bounds);
            }

            // Step 3: Compute Pivot Offset (Bottom-Center)
            Vector3 bottomCenterWorld = new Vector3(combinedBounds.center.x, combinedBounds.min.y, combinedBounds.center.z);

            // Step 4: Construct Isolated Hierarchy
            GameObject entityRoot = new GameObject(selectedObject.name + "_Normalized");
            GameObject visualsParent = new GameObject("Visuals");
            visualsParent.transform.SetParent(entityRoot.transform, false);

            // Position raw instance under Visuals parent offset by -bottomCenter
            rawInstance.transform.SetParent(visualsParent.transform, false);
            rawInstance.transform.position = -bottomCenterWorld;

            // Align Forward Vector to +Z if necessary
            entityRoot.transform.rotation = Quaternion.identity;

            // Step 5: Add Root Physics & Collider Isolation
            Rigidbody rb = entityRoot.AddComponent<Rigidbody>();
            rb.mass = 1.0f;
            rb.constraints = RigidbodyConstraints.FreezeRotationX | RigidbodyConstraints.FreezeRotationZ;

            // Encapsulate Collider on Root based on calculated dimensions
            CapsuleCollider capsule = entityRoot.AddComponent<CapsuleCollider>();
            capsule.height = combinedBounds.size.y;
            capsule.radius = Mathf.Max(combinedBounds.size.x, combinedBounds.size.z) / 2.0f;
            capsule.center = new Vector3(0, combinedBounds.size.y / 2.0f, 0); // Bottom-grounded collider

            // Step 6: Create & Bind URP Material
            ApplyURPMaterial(rawInstance, assetPath);

            // Step 7: Save Normalized Prefab
            string outputDir = "Assets/Prefabs/MeshyNormalized/";
            if (!Directory.Exists(outputDir))
            {
                Directory.CreateDirectory(outputDir);
            }

            string prefabPath = Path.Combine(outputDir, selectedObject.name + "_Prefab.prefab");
            prefabPath = AssetDatabase.GenerateUniqueAssetPath(prefabPath);

            PrefabUtility.SaveAsPrefabAsset(entityRoot, prefabPath);

            // Cleanup scene instances
            Object.DestroyImmediate(entityRoot);

            AssetDatabase.SaveAssets();
            AssetDatabase.Refresh();

            Debug.Log($"<color=green>[MeshyPipeline] Successfully built normalized URP prefab at: {prefabPath}</color>");
        }

        private static void ApplyURPMaterial(GameObject targetInstance, string fbxAssetPath)
        {
            Shader urpShader = Shader.Find("Universal Render Pipeline/Lit");
            if (urpShader == null)
            {
                Debug.LogWarning("[MeshyPipeline] URP/Lit shader not found. Ensure URP is active in Graphics Settings.");
                return;
            }

            string directory = Path.GetDirectoryName(fbxAssetPath);
            string baseName = Path.GetFileNameWithoutExtension(fbxAssetPath);

            // Locate BaseColor Texture
            string[] matchingTextures = AssetDatabase.FindAssets($"{baseName} t:Texture2D", new[] { directory });
            Texture2D baseColorTex = null;
            Texture2D normalTex = null;

            foreach (string guid in matchingTextures)
            {
                string path = AssetDatabase.GUIDToAssetPath(guid);
                string lowerPath = path.ToLower();

                if (lowerPath.Contains("basecolor") || lowerPath.Contains("albedo") || lowerPath.Contains("diffuse"))
                {
                    baseColorTex = AssetDatabase.LoadAssetAtPath<Texture2D>(path);
                }
                else if (lowerPath.Contains("normal") || lowerPath.Contains("norm"))
                {
                    normalTex = AssetDatabase.LoadAssetAtPath<Texture2D>(path);
                }
            }

            if (baseColorTex != null)
            {
                Material urpMat = new Material(urpShader);
                urpMat.name = $"{baseName}_Mat";
                urpMat.SetTexture("_BaseMap", baseColorTex);
                urpMat.SetColor("_BaseColor", Color.white);

                if (normalTex != null)
                {
                    urpMat.SetTexture("_BumpMap", normalTex);
                    urpMat.EnableKeyword("_NORMALMAP");
                }

                // Force Opaque Render Queue
                urpMat.SetFloat("_Surface", 0); // 0 = Opaque, 1 = Transparent
                urpMat.SetInt("_SrcBlend", (int)UnityEngine.Rendering.BlendMode.One);
                urpMat.SetInt("_DstBlend", (int)UnityEngine.Rendering.BlendMode.Zero);
                urpMat.SetInt("_ZWrite", 1);
                urpMat.renderQueue = (int)UnityEngine.Rendering.RenderQueue.Geometry;

                // Save Material Asset
                string matPath = Path.Combine(directory, $"{baseName}_URPMat.mat");
                AssetDatabase.CreateAsset(urpMat, matPath);

                // Assign to Renderers
                MeshRenderer[] renderers = targetInstance.GetComponentsInChildren<MeshRenderer>();
                foreach (MeshRenderer rend in renderers)
                {
                    rend.sharedMaterial = urpMat;
                }
            }
        }
    }
}
#endif
```

## 6. Verification & Troubleshooting Matrix

| Symptom / Issue | Primary Root Cause | Automated Pipeline Remedy |
| :--- | :--- | :--- |
| **Material renders invisible or black in URP** | BaseColor PNG exports contain solid 0-alpha channel read by URP Lit as transparent. | Set `alphaSource = TextureImporterAlphaSource.None` and `alphaIsTransparency = false` in `OnPreprocessTexture`. |
| **Normal maps have seam lines or flipped shading** | Incompatible tangent algorithm or custom split normals in raw FBX. | Force `importNormals = Calculate` (60° smooth angle) and `importTangents = CalculateMikk` in `OnPreprocessModel`. |
| **Model appears 100x too small or large** | FBX unit scaling mismatch (Maya 0.01 vs Unity 1.0). | Force `globalScale = 1.0f`, `useFileScale = false`, and `bakeAxisConversion = true`. |
| **Model floats above ground or sinks into terrain** | Pivot is located at geometric center of mesh instead of bottom. | Automated bounds calculation offsets Visuals parent by `-bottomCenterWorld`, anchoring root at `(0,0,0)`. |
| **Physics jitter or non-uniform collider scaling** | Collider attached directly to visual mesh with rotation/scale offsets. | Isolate `Rigidbody` and `CapsuleCollider` on root GameObject; isolate visual meshes under `Visuals` child node. |
| **Dark lighting / dull colors** | BaseColor map imported in Linear space instead of sRGB. | Set `sRGBTexture = true` for Albedo maps and `sRGBTexture = false` for data maps (Normal/Metallic). |

## 7. Recommended Workflow Summary

1. Save `MeshyModelPostprocessor.cs` and `MeshyTexturePostprocessor.cs` in an `Editor` folder (e.g. `Assets/Editor/MeshyPipeline/`).
2. Import raw Meshy AI FBX exports and PNG textures into `Assets/Art/MeshyAI/`.
3. Unity automatically executes scale baking, normal/tangent computation, and PNG alpha removal on import.
4. Select the imported FBX in Unity and run **Tools > Meshy AI > Normalize & Build Selected Model Prefab**.
5. The normalized, physics-isolated URP prefab with correct bottom-center pivot and bound materials is generated in `Assets/Prefabs/MeshyNormalized/`.
